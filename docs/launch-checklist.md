# 배포 체크리스트와 3주 관찰 프로토콜

이 사이트의 가설은 하나다. **홍보 없이도 검색만으로 유입이 생기는가.**
그래서 배포 후 3주 동안 아무것도 홍보하지 않고 색인만 관찰한다.

커뮤니티에 올리거나 지인에게 공유하면 그 트래픽이 섞여서 가설을 검증할 수 없게 된다.
3주를 참는 것이 이 프로토콜의 핵심이다.

---

## A. 배포 전 점검

데이터가 실려 있어야 의미가 있다. 표본 데이터로 배포하면 색인된 페이지가 나중에 사라져 손해다.

- [ ] `data/universities.json`이 전량 데이터인가 (377개교)
- [ ] `scripts/validate.mjs` 판정이 **통과**인가
- [ ] 결측률이 항목별 20% 미만인가 — 80%대면 수집이 실패한 것이다
- [ ] `npm run build`가 통과하고 생성 페이지 수가 예상과 맞는가

기술 점검.

- [ ] `NEXT_PUBLIC_SITE_URL`이 실제 도메인으로 설정돼 있는가
- [ ] `sitemap.xml`에 `example.com`이 남아 있지 않은가
- [ ] `robots.txt`가 `Allow: /` 이고 sitemap 주소가 실제 도메인인가
- [ ] 학교 페이지 3곳을 열어 canonical, title, description이 학교마다 다른가
- [ ] 결측이 많은 학교 페이지가 깨지지 않는가 (교육비 미공시 학교로 확인)
- [ ] 모바일 화면에서 결론 문장과 지표 카드가 읽히는가

편집 원칙 점검. 이 사이트는 실명 기관의 재정을 다룬다.

- [ ] 순위표가 어디에도 없는가
- [ ] 자체 점수·등급이 없는가
- [ ] 모든 수치에 공시 항목명과 기준연도가 붙어 있는가
- [ ] 환원율에 **계산값** 표시와 산식이 붙어 있는가
- [ ] 단정적 가치 판단 문구가 없는가
- [ ] 결측이 0으로 채워지지 않고 사유가 구분돼 있는가
- [ ] 코드 전체에 이모지가 0건인가

---

## B. 배포 직후 (D+0)

- [ ] 네이버 서치어드바이저 등록·소유확인·사이트맵 제출 (`indexing.md` 1번)
- [ ] Google Search Console 속성 추가·사이트맵 제출 (`indexing.md` 2번)
- [ ] Vercel Analytics 활성화 및 `/_vercel/insights/view` 요청 확인
- [ ] 관찰 기록표 첫 줄 작성 (아래 C)

**그리고 3주간 홍보하지 않는다.**

---

## C. 3주 관찰 프로토콜

주 1회, 같은 요일 같은 시간에 기록한다. 매일 보면 노이즈만 본다.

관찰 항목은 넷이다.

| 항목 | 어디서 보나 |
|---|---|
| **색인된 페이지 수** | Search Console → 페이지 → 색인 생성됨 / 네이버 → 수집 현황 |
| **검색 노출 수** | Search Console → 실적 → 총 노출수 |
| **검색 유입 수** | Search Console → 실적 → 총 클릭수 / Vercel Analytics 방문 수 |
| **유입 상위 키워드** | Search Console → 실적 → 검색어 |

| 주차 | 날짜 | 구글 색인 | 네이버 수집 | 노출 | 클릭 | 상위 키워드 |
|---|---|---|---|---|---|---|

| 2주 | | | | | | |
| 3주 | | | | | | |

### 해석 기준

3주 뒤에 판단할 것은 "많이 왔나"가 아니라 **"색인이 도는가"**다.

| 관찰 | 뜻 | 대응 |
|---|---|---|
| 색인 페이지가 꾸준히 는다 | 정상. 구조가 작동한다 | 그대로 두고 4주차부터 지역 페이지 추가 |
| 색인이 10개 언저리에서 멈춘다 | 내부링크가 부족하거나 사이트맵이 안 읽힌다 | 사이트맵 상태 확인, 관련 학교 링크 밀도 점검 |
| 색인은 되는데 노출이 0이다 | 검색 수요가 없는 키워드로만 잡혔다 | title·description 문구 재검토 |
| 노출은 있는데 클릭이 없다 | 제목이 검색 의도와 안 맞는다 | 학교명 + 등록금 조합으로 title 조정 |
| 네이버만 아무 반응이 없다 | 등록 누락이거나 아직 이른 시점 | 소유확인 상태 확인, 4주까지 기다린다 |

**색인 속도가 느린 것 자체는 문제가 아니다.** 새 도메인은 원래 느리다.
문제로 볼 것은 "색인이 아예 늘지 않는" 상태다.

## D. 3주 뒤 결정

관찰 결과에 따라 다음 중 하나를 고른다. 지금 미리 정하지 않는다.

- 색인이 도는 경우 → 지역 페이지 17개를 추가해 내부링크 허브를 늘린다
- 색인이 멈춘 경우 → 원인을 먼저 잡는다. 페이지를 더 만들어도 같은 벽에 막힌다
- 특정 키워드로만 유입되는 경우 → 그 키워드에 맞춰 페이지 구조를 조정한다

---

## E. 하지 않을 것

- 순위 콘텐츠를 만들어 트래픽을 끌어오지 않는다. 이 사이트는 실명 기관의 재정을 다룬다
- 3주 안에 홍보하지 않는다. 가설 검증이 불가능해진다
- 색인이 느리다고 페이지를 더 찍어내지 않는다. 원인부터 잡는다
